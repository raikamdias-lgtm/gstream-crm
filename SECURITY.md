# Política de Segurança

Se você encontrar uma vulnerabilidade de segurança no Gstream CRM, não publique detalhes sensíveis em uma issue pública.

Entre em contato com o responsável pelo projeto de forma privada, informando:

- descrição da vulnerabilidade;
- passos para reprodução;
- impacto observado;
- versão ou commit afetado.

Nunca envie tokens, senhas ou outras credenciais reais em issues, pull requests ou mensagens públicas.
